Severity Classification

Policy Risk Assessment

NIST SP 800-41 based urgency classification. Set User IP ranges and click Classify to assess all Severity levels (1–7). Severity 1, 2, and 7 can be determined even without IP ranges configured.

Guide

Severity Classification Criteria

SeverityRisk LevelActionClassification CriteriaNotes
7 None Keep ① Action = Deny
② ICMP-only service (Ping, etc.)
③ Valid ITS ticket (ticket ID present + schedule not expired)
④ Policy name contains "controlled" (multi-firewall passthrough)
⑤ Policy matches a configured admin object		 Exception policies — not subject to disable or deletion
1 Critical Disable Immediately ① Source, destination, and service are all Any/All
② Source or destination Any/All + Hit Count = 0
③ Source or destination Any/All + Hit Count > 0 but Last Used ≥ 1 year
④ Risky service only (FTP, TELNET, TFTP, RLOGIN, RSH)
⑤ Risky + normal service mixed + Hit Count = 0 or Last Used ≥ 1 year
⑥ Temp keyword in name (temp, etc.) + No ITS Request + Hit Count = 0
⑦ Service ALL + Hit Count = 0 or Last Used ≥ 1 year		 After disabling, delete once Hit Count confirms 0
2 High Delete Required ① Status = Disabled
② Schedule expired (YYMMDD date is in the past)
③ Hit=0 + Accept + Server↔User + registered ≥ 1 year ago
④ Hit=0 + Accept + Server - Server + always schedule + > 1 year		 Policies registered < 1 year are excluded. S-S date schedules apply a 2-year threshold
3 Medium Additional Review Required ① Server - User + registered > 1 year + Hit < elapsed years×100 + Last Used ≥ 1 year
② Risky + normal service mixed + actively used (within 1 year)
③ Source/Destination Any·All + active use (within 1yr) + Server - User
④ Service ALL + active use (within 1yr) + Server - User		 ② Mixed risky policy: do NOT delete the entire rule — remove only the risky service/port, keep normal services
4 Medium Additional Review Required ① Server - Server + registered > 2 years + Hit < 50
② Server - Server + registration date unknown
③ Source/Destination Any·All + active use (within 1yr) + Server - Server
④ Service ALL + active use (within 1yr) + Server - Server		 For active Any/All policies, recommend narrowing scope instead of immediate disable
5 Low Request ITS Ticket ① Server - User + registered < 1 year + no ticket ID
② Server - User + registered > 1 year + insufficient hits + Last Used < 1 year (recently active but not formally registered)
③ Service ALL + active use (within 1yr) + Server - User		 Keep policy but formally register it via ITS Ticket
6 Low Request ITS Ticket ① AD/DNS/LDAP authentication service + Hit > 0
② Server - Server + within 2 years + no ticket ID
③ Server - Server + Hit ≥ 50
④ A configured infrastructure or management object is included		 Keep policy but formally register it via ITS Ticket

※ Without User IP ranges configured, traffic type (Server/User) cannot be determined — Severity 1, 2, and 7 can still be assessed without IP ranges
